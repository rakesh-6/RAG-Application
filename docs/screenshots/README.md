# Screenshots

The main README shows these images. Take them yourself, from the app running locally with your real Gemini key, so they show real answers. Save them in this folder with **exactly these names**:

| File | What to capture |
|---|---|
| `chat.png` | The Chat page with an answer to a question about one of your documents: the citation numbers in the text and the source cards underneath. A follow-up question with its "Searched for: …" line is a bonus |
| `documents.png` | The Documents page with a few **Ready** documents (one **Failed** row also helps show the error handling) |
| `not-found.png` | The amber "I couldn't find this in your documents." answer to a question your documents don't cover |
| `login.png` | The Log in page |

**How:** make the browser window about 1280 px wide, press **Win + Shift + S**, select the browser content, then paste into Paint and save as PNG (or use the Snipping Tool's save button).

Use fictional or public documents only, so nothing private ends up on GitHub.
